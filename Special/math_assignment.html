Q1
Cauchy's Integral Formula  Complex Analysis
Evaluate \(\displaystyle\oint_C \frac{\cos\pi z^2}{(z-1)(z-2)}\,dz\), where \(C\) is \(|z|=\tfrac{3}{2}\).
Step 1 — Identify & Locate Singularities

The integrand has simple poles at \(z=1\) and \(z=2\).

✔ \(|z=1|=1 < \tfrac{3}{2}\) → inside \(C\)

✘ \(|z=2|=2 > \tfrac{3}{2}\) → outside \(C\)

Step 2 — Apply Cauchy's Integral Formula

Write the integral with \(f(z)=\dfrac{\cos\pi z^2}{z-2}\), which is analytic inside \(C\):

\[\oint_C \frac{\cos\pi z^2}{(z-1)(z-2)}\,dz = \oint_C \frac{f(z)}{z-1}\,dz = 2\pi i\cdot f(1)\]
Step 3 — Evaluate
\[f(1) = \frac{\cos(\pi\cdot1^2)}{1-2} = \frac{\cos\pi}{-1} = \frac{-1}{-1} = 1\]
Answer
\[\oint_C \frac{\cos\pi z^2}{(z-1)(z-2)}\,dz = 2\pi i\]
Q2
Residue Theorem  Complex Analysis
Evaluate \(\displaystyle\oint_C \frac{z+4}{z^2+2z+5}\,dz\), where \(C\) is \(|z+1+i|=2\).
Step 1 — Find Poles

Solve \(z^2+2z+5=0\):

\[z = \frac{-2\pm\sqrt{4-20}}{2} = -1\pm 2i\]

Poles: \(z_1=-1+2i\) and \(z_2=-1-2i\).

Step 2 — Locate Poles Relative to C (centre \(-1-i\), radius 2)

✘ \(|z_1-(-1-i)|=|{-1+2i+1+i}|=|3i|=3>2\) → outside

✔ \(|z_2-(-1-i)|=|{-1-2i+1+i}|=|-i|=1<2\) → inside

Step 3 — Compute Residue at \(z_2=-1-2i\)
\[\text{Res}_{z_2} = \frac{z_2+4}{z_2-z_1} = \frac{(-1-2i)+4}{(-1-2i)-(-1+2i)} = \frac{3-2i}{-4i}\]

Multiply numerator and denominator by \(i\):

\[\frac{(3-2i)\cdot i}{-4i^2} = \frac{3i-2i^2}{4} = \frac{3i+2}{4} = \frac{2+3i}{4}\]
Step 4 — Apply Residue Theorem
\[\oint_C = 2\pi i\cdot\frac{2+3i}{4} = \frac{\pi i(2+3i)}{2} = \frac{2\pi i + 3\pi i^2}{2} = \frac{-3\pi+2\pi i}{2}\]
Answer
\[\oint_C \frac{z+4}{z^2+2z+5}\,dz = \frac{\pi}{2}(-3+2i)\]
Q3
Cauchy's Integral Formula  Complex Analysis
Evaluate \(\displaystyle\oint_C \frac{z^3}{2z-1}\,dz\), where \(C\) is \(|z|=1\).
Step 1 — Rewrite
\[\frac{z^3}{2z-1} = \frac{z^3}{2\!\left(z-\tfrac{1}{2}\right)} = \frac{1}{2}\cdot\frac{z^3}{z-\tfrac{1}{2}}\]

Pole at \(z_0=\tfrac{1}{2}\); since \(\bigl|\tfrac{1}{2}\bigr|=\tfrac{1}{2}<1\), it lies inside \(C\).

Step 2 — Apply Cauchy's Formula with \(f(z)=z^3\)
\[\oint_C \frac{z^3}{2z-1}\,dz = \frac{1}{2}\oint_C\frac{z^3}{z-\tfrac{1}{2}}\,dz = \frac{1}{2}\cdot 2\pi i\cdot f\!\left(\tfrac{1}{2}\right)\]
\[= \pi i\cdot\left(\frac{1}{2}\right)^{\!3} = \frac{\pi i}{8}\]
Answer
\[\oint_C \frac{z^3}{2z-1}\,dz = \frac{\pi i}{8}\]
Q4
Differential Equations — Concept & Applications  Theory

Definition. A differential equation (DE) is an equation relating a function to its derivatives. If the unknown function depends on one variable, it is an ordinary differential equation (ODE); if on several variables, a partial differential equation (PDE). The order is the highest derivative present; the degree is the power of that highest-order derivative.

General form (1st-order, 1st-degree ODE):

\[\frac{dy}{dx} = f(x,\,y)\]

Key types and examples:

Separable  ·  \(\dfrac{dy}{dx}=g(x)h(y)\)

Example: \(\dfrac{dy}{dx}=xy\) → Separating: \(\dfrac{dy}{y}=x\,dx\) → \(y=Ce^{x^2/2}\).

Linear First-Order  ·  \(\dfrac{dy}{dx}+P(x)y=Q(x)\)

Solved with integrating factor \(\mu=e^{\int P\,dx}\). Example: RC circuit discharge: \(R\,\dfrac{dq}{dt}+\dfrac{q}{C}=0\).

Second-Order Linear  ·  \(ay''+by'+cy=f(x)\)

Example: simple harmonic oscillator \(m\ddot{x}+kx=0\) → \(x=A\cos\omega t+B\sin\omega t\).

Applications in ECE / EE / CE:

  • Electrical Engineering: RL, RC, RLC circuit analysis — voltage/current transients.
  • Electronics: transistor small-signal models, phase-locked loop dynamics.
  • Civil Engineering: beam deflection \(EI\,y''=M(x)\), soil settlement models.
  • Control & Communication: system transfer functions, signal processing filters.
  • Computer Engineering: numerical methods for solving DEs (Euler, Runge–Kutta) underlie simulation tools (SPICE, MATLAB/Simulink).
Q5
Solving ODEs  Three Parts
(i)   \(x(1-x^2)\,\dfrac{dy}{dx}+(2x^2-1)y=ax^3\)
Rewrite as Standard Linear Form
\[\frac{dy}{dx}+\underbrace{\frac{2x^2-1}{x(1-x^2)}}_{P(x)}\,y = \underbrace{\frac{ax^2}{1-x^2}}_{Q(x)}\]
Partial Fractions for P(x)

Write \(\dfrac{2x^2-1}{x(1-x)(1+x)}=\dfrac{A}{x}+\dfrac{B}{1-x}+\dfrac{C}{1+x}\).

Setting \(x=0: A=-1\); \(x=1: B=\tfrac{1}{2}\); \(x=-1: C=-\tfrac{1}{2}\).

Integrating Factor
\[\int P\,dx = -\ln x -\tfrac{1}{2}\ln(1-x)-\tfrac{1}{2}\ln(1+x) = -\ln x - \tfrac{1}{2}\ln(1-x^2)\]
\[\mu = \frac{1}{x\sqrt{1-x^2}}\]
Integrate
\[\mu\cdot Q = \frac{ax^2}{1-x^2}\cdot\frac{1}{x\sqrt{1-x^2}} = \frac{ax}{(1-x^2)^{3/2}}\]

Let \(u=1-x^2\), \(du=-2x\,dx\):

\[\int \frac{ax}{(1-x^2)^{3/2}}\,dx = -\frac{a}{2}\int u^{-3/2}\,du = \frac{a}{\sqrt{1-x^2}}+C\]
General Solution
\[\frac{y}{x\sqrt{1-x^2}} = \frac{a}{\sqrt{1-x^2}}+C \quad\Longrightarrow\quad \boxed{y = ax + Cx\sqrt{1-x^2}}\]
(ii)   \((x^2-x)\,\dfrac{dy}{dx}-(2x^2-1)y = x^5-2x^3+x\)
Standard Linear Form (divide by \(x^2-x\))
\[\frac{dy}{dx}-\frac{2x^2-1}{x(x-1)}\,y = \frac{x(x^2-1)^2}{x(x-1)} = (x-1)(x+1)^2\]
Partial Fractions for \(\dfrac{2x^2-1}{x(x-1)}\)

Polynomial division: \(\dfrac{2x^2-1}{x(x-1)}= 2+\dfrac{2x-1}{x(x-1)}= 2+\dfrac{1}{x}+\dfrac{1}{x-1}\).

Integrating Factor
\[\int -\!\left(2+\frac{1}{x}+\frac{1}{x-1}\right)dx = -2x-\ln x -\ln(x-1)\]
\[\mu = \frac{e^{-2x}}{x(x-1)}\]
Homogeneous (Complementary) Solution
\[y_c = C\,x(x-1)e^{2x}\]
Particular Integral via Variation of Parameters

Set \(y=v\cdot x(x-1)e^{2x}\). Substituting gives:

\[v' = \frac{(x+1)^2 e^{-2x}}{x} = \left(x+2+\frac{1}{x}\right)e^{-2x}\]

Integrating term-by-term:

\[\int xe^{-2x}dx = -\frac{e^{-2x}(2x+1)}{4}, \qquad \int 2e^{-2x}dx = -e^{-2x}\]
\[\int\frac{e^{-2x}}{x}dx = \operatorname{Ei}(-2x) \quad\text{(Exponential Integral)}\]
General Solution
\[y = x(x-1)e^{2x}\!\left[-\frac{(2x+5)}{4}\,e^{-2x}+\operatorname{Ei}(-2x)+C\right]\]

where \(\operatorname{Ei}(-2x)=-\!\displaystyle\int_{2x}^{\infty}\frac{e^{-t}}{t}\,dt\) is the standard Exponential Integral.

(iii)   \((1+y^2)\,dx = (\tan^{-1}y - x)\,dy\)
Treat x as a Function of y
\[\frac{dx}{dy}+\frac{x}{1+y^2} = \frac{\tan^{-1}y}{1+y^2}\]

This is linear in \(x\) with \(P=\dfrac{1}{1+y^2}\), \(Q=\dfrac{\tan^{-1}y}{1+y^2}\).

Integrating Factor
\[\mu = e^{\int \frac{dy}{1+y^2}} = e^{\tan^{-1}y}\]
Integrate Both Sides
\[\frac{d}{dy}\!\left[x\,e^{\tan^{-1}y}\right] = \frac{\tan^{-1}y}{1+y^2}\,e^{\tan^{-1}y}\]

Substitute \(t=\tan^{-1}y\), \(dt=\dfrac{dy}{1+y^2}\):

\[\int t\,e^t\,dt = (t-1)e^t+C = (\tan^{-1}y-1)\,e^{\tan^{-1}y}+C\]
General Solution
\[x\,e^{\tan^{-1}y} = (\tan^{-1}y-1)\,e^{\tan^{-1}y}+C\] \[\boxed{x = \tan^{-1}y - 1 + C\,e^{-\tan^{-1}y}}\]
Q6
General & Singular Solutions  Clairaut-type
Obtain general and singular solutions of \(y = px+\sqrt{p^2x^2+b^2}\), where \(p=\dfrac{dy}{dx}\).
Step 1 — Eliminate the Square Root

Rearrange: \(y-px = \sqrt{p^2x^2+b^2}\). Square both sides:

\[(y-px)^2 = p^2x^2+b^2 \;\Longrightarrow\; y^2-2pxy+p^2x^2 = p^2x^2+b^2\]
\[y^2 - 2pxy = b^2 \quad\Longrightarrow\quad p = \frac{y^2-b^2}{2xy}\]
Step 2 — Reduce to a Separable ODE

Use the homogeneous substitution \(y=vx\), so \(p=v+xv'\):

\[x\frac{d(y^2)}{dx} = y^2 - b^2\]

Let \(w=y^2\):

\[\frac{dw}{w-b^2} = \frac{dx}{x} \;\Longrightarrow\; \ln|w-b^2| = \ln|x|+\ln|C|\]
Step 3 — General Solution
\[y^2 = Cx + b^2\]

Verify: with \(y^2=Cx+b^2\), we get \(p=\dfrac{C}{2y}\). Then

\[px+\sqrt{p^2x^2+b^2} = \frac{Cx}{2y}+\frac{y^2+b^2}{2y} = \frac{Cx+y^2+b^2}{2y} = \frac{2y^2}{2y} = y\;\checkmark\]
Step 4 — Singular Solution (Envelope)

The envelope of the family \(y^2=Cx+b^2\) is found by eliminating \(C\). Differentiate with respect to \(C\):

\[\frac{\partial}{\partial C}(y^2-Cx-b^2)=0 \;\Longrightarrow\; x=0\]

Substituting \(x=0\) back: \(y^2=b^2\), so \(y=\pm b\).

Check \(y=b\): \(p=0\), so \(px+\sqrt{p^2x^2+b^2}=b=y\). ✔

Check \(y=-b\): \(px+\sqrt{p^2x^2+b^2}=b\neq -b\). ✘

Answers

General solution: \(y^2 = Cx + b^2\)  (family of parabolas)

Singular solution: \(y = b\)  (tangent to all parabolas at \(x=0\))
